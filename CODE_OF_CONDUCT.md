# Code of conduct

This repository is where Lineward's users report problems, ask questions and propose changes to the files it holds.
One person maintains it. These few rules apply to every issue, discussion, pull request and comment here.

## What is expected

- Be respectful: write about the problem, never about the person.
- Stay on the subject of this repository: the product, its plugin and its setup pages.
- Keep private things private: no personal data, no licence key, no SQL or data of your own or of your employer.

## What is not accepted

Insults, harassment, threats, discriminatory or sexual language or images, publishing someone's private information,
spam and advertising.

## What the maintainer does

The maintainer may edit, hide or delete a contribution, lock a thread, and block an account from this repository,
without a warning when the behaviour calls for none. There is no scale of sanctions and no appeal.
[GitHub's Community Guidelines](https://docs.github.com/en/site-policy/github-terms/github-community-guidelines) apply
here as everywhere on GitHub, and abuse can also be
[reported to GitHub](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam)
directly.

## Reporting a behaviour

Write to <conduct@lineward.dev> with a link to what happened. The maintainer alone reads that address, and answers on
a best-effort basis, like all support here: no delay is promised. A security vulnerability is not reported there:
see [SECURITY.md](SECURITY.md).
